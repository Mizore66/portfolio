Gate 5: the Work room and the project pages

Phase 5, step 4, first part. The brief asks for one Gate 5 per page, so step 4 is reviewed page by page: this gate covers the Work index (/work, key frame work-c) and the three project pages (/work/faultline, /work/gemini-teleportal, /work/circuitmindai, key frame proj-a). The roles index, role pages, Lab chapters and contact follow once you approve this one. Build: src/components/work/, src/components/project/, src/app/work/.

How the evidence was made. This session ran in a cloud container with no GPU, so WebGL is drawn on the CPU (one hero frame takes about 2.4 s). Real-time recordings would show the CPU, not the design. Instead, page changes were run in slow motion (30×: GSAP, the page-change clocks and WAAPI together, development only, src/lib/motion/slowmo.ts) and a frame was taken at each listed instant of animation time (design/build/_frames.cjs). The stills are 2× like the key frames (design/build/_stills.cjs). Real-time recordings on a GPU (design/build/_record.cjs) are still to do on your machine.
