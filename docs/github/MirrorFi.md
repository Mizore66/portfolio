# MirrorFi

A Next.js desk draws the vault line; Node.js talks to Drift, Jupiter, and Meteora; MongoDB stores the copy so another desk can run it. Grand Prize, Solana Megahack 2025.

The public clipping is the exhibit: [Opening Preparation · MirrorFi](https://anasqumhiyeh.dev/projects/mirrorfi).

## What runs

Next.js 15 app in this repository (`npm run dev`, `npm run build`, `npm start`). App Router under `app/`. UI in `components/`. No separate backend package — the desk is the product.

## Receipts to run it

```bash
npm install
npm run dev
```

```bash
npm run build
npm start
```
